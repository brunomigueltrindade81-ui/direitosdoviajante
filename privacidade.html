Política de Privacidade

O Direitos do Viajante valoriza a privacidade dos seus visitantes. Esta página explica, de forma simples, como funciona o tratamento de dados associado à utilização deste website.

1. Dados pessoais

O Direitos do Viajante não disponibiliza atualmente formulários próprios para recolha de dados pessoais, nem solicita diretamente ao visitante informações como nome, morada ou número de telefone.

A utilização normal do website consiste na consulta dos conteúdos informativos disponibilizados nas suas páginas.

2. Alojamento e funcionamento do website

Este website utiliza serviços de infraestrutura e distribuição de conteúdos necessários ao seu funcionamento. Durante o acesso a um website podem ser tratados dados técnicos, como endereço IP, informações do navegador, sistema operativo e dados relacionados com o tráfego.

3. Ligações de afiliado

Algumas páginas do Direitos do Viajante contêm ligações para serviços externos, incluindo ligações de afiliado para a AirHelp.

Quando o visitante utiliza uma dessas ligações, é encaminhado para o website do respetivo fornecedor. A partir desse momento, o tratamento de dados pessoais, cookies e outras tecnologias utilizadas pelo fornecedor está sujeito às respetivas políticas de privacidade e cookies.

As ligações de afiliado podem conter parâmetros técnicos que permitem identificar que o visitante chegou ao serviço através do Direitos do Viajante.

4. Cookies

O Direitos do Viajante não utiliza atualmente cookies próprios para criar contas de utilizadores ou recolher diretamente dados pessoais.

Os serviços externos para os quais este website encaminha o visitante podem utilizar cookies ou tecnologias semelhantes. A utilização dessas tecnologias depende das políticas dos respetivos fornecedores.

5. Serviços externos

Ao seguir uma ligação para outro website, o visitante passa a estar sujeito às condições e políticas de privacidade desse website. Recomenda-se a consulta dessas informações antes de fornecer dados pessoais ou contratar qualquer serviço.

6. Segurança

São adotadas medidas razoáveis para manter o website disponível e protegido contra acessos indevidos. No entanto, nenhum sistema disponível através da Internet pode garantir segurança absoluta.

7. Alterações a esta política

Esta política poderá ser atualizada caso sejam adicionadas novas funcionalidades, ferramentas de análise, publicidade, formulários ou outros serviços que alterem a forma como os dados são tratados.

8. Contacto

Para questões relacionadas com este website ou com esta política, deverá ser utilizado um contacto disponibilizado pelo responsável pelo Direitos do Viajante.

Nota: esta política descreve o funcionamento atual conhecido do website e deverá ser revista sempre que sejam adicionados novos serviços ou funcionalidades que envolvam o tratamento de dados pessoais.

# VooJusto — MVP
Versão estática inicial do projeto.

## Antes de publicar
1. Substituir o link placeholder em `verificar.html` pelo URL de afiliado aprovado.
2. Rever política de privacidade/cookies conforme as ferramentas realmente usadas.
3. Adicionar contacto e identificação do responsável pelo site.
4. Rever o conteúdo jurídico antes da publicação.
5. Confirmar aprovação do programa de afiliados.
